# شروع سریع — برق خودرو مهندس

این بسته برای ساخت خودکار APK با GitHub Actions آماده شده است. برای ساخت خودکار، لازم نیست روی ویندوز Java یا Android SDK جداگانه نصب کنید؛ GitHub در فضای ابری APK را می‌سازد.

## روش پیشنهادی: ساخت خودکار بدون نصب ابزار برنامه‌نویسی

1. وارد https://github.com شوید و یک حساب بسازید یا وارد حساب خود شوید.
2. از علامت `+` گزینه **New repository** را بزنید.
3. نام مخزن را مثلاً `bargh-khodro-mohandes` بگذارید و آن را **Private** انتخاب کنید؛ سپس **Create repository**.
4. ZIP همین بسته را روی کامپیوتر Extract کنید.
5. وارد پوشه استخراج‌شده شوید و همه فایل‌ها و پوشه‌های داخل آن (از جمله پوشه `.github`) را در صفحه مخزن GitHub با **Add file → Upload files** بارگذاری کنید. خود پوشه‌ی مادر را یک لایه اضافه نکنید؛ فایل `settings.gradle` باید در ریشه مخزن دیده شود.
6. پایین صفحه روی **Commit changes** بزنید.
7. در مخزن، تب **Actions** را باز کنید. گردش‌کار **Build Android APK** باید اجرا شده باشد. اگر اجرا نشد: وارد آن شوید و **Run workflow** را بزنید.
8. پس از سبز شدن اجرای Build، همان صفحه را پایین بیاورید و از بخش **Artifacts** فایل `bargh-khodro-mohandes-debug-apk` را دانلود کنید.
9. ZIP دانلودشده را Extract کنید. فایل `app-debug.apk` همان فایل نصب برنامه است.
10. APK را به گوشی اندرویدی منتقل و نصب کنید. ممکن است اندروید اجازه نصب از همان برنامه فایل‌منیجر/مرورگر را بخواهد؛ فقط در صورت اعتماد به فایل، اجازه بدهید.

## اگر می‌خواهید روی ویندوز خودتان بسازید

1. **Android Studio** را فقط از سایت رسمی نصب کنید: https://developer.android.com/studio
2. در Setup Wizard نصب اجزای پیشنهادی را تأیید کنید. Android Studio شامل JDK مناسب است؛ معمولاً نصب Java جداگانه لازم نیست.
3. از **SDK Manager** مطمئن شوید Android SDK Platform 35 و Android SDK Build-Tools نصب شده‌اند.
4. Android Studio → **Open** → پوشه‌ای را انتخاب کنید که فایل `settings.gradle` مستقیماً داخل آن است.
5. صبر کنید Gradle Sync کامل شود؛ اگر درخواست نصب SDK یا پذیرش مجوزها آمد، تأیید کنید.
6. از منوی **Build → Build Bundle(s) / APK(s) → Build APK(s)** استفاده کنید.
7. خروجی Debug معمولاً در `app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود.

## مشخصات و محدودیت‌های نسخه فعلی

- نام نمایشی: برق خودرو مهندس
- شناسه برنامه: `ir.barghkhodro.mohandes`
- حداقل اندروید: Android 6.0 (API 23)
- برنامه برای استفاده آفلاین طراحی شده است.
- اطلاعات نسخه فعلی در فضای محلی WebView (localStorage) ذخیره می‌شود. حذف برنامه یا پاک‌کردن داده‌های آن می‌تواند اطلاعات را پاک کند؛ مرتباً از بخش پشتیبان‌گیری خروجی JSON بگیرید و آن را خارج از گوشی نگه دارید.
- پیامک از طریق برنامه پیامک گوشی باز می‌شود و ارسال نهایی را کاربر تأیید می‌کند.
- Caller ID خودکار هنوز در این نسخه پیاده‌سازی نشده است.
- این بسته سورس پروژه و گردش‌کار ساخت است، نه APK آماده. APK تنها پس از اجرای موفق Build در GitHub یا Android Studio تولید می‌شود.
- پیش از استفاده روزمره، نسخه ساخته‌شده را روی گوشی آزمایش کنید و یک نسخه پشتیبان آزمایشی بگیرید.
