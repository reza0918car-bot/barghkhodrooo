# برق خودرو مهندس — نسخه ۱.۱ آفلاین

این پروژه یک اپلیکیشن اندرویدی فارسی و راست‌چین برای مدیریت تعمیرگاه است. داده‌ها در حافظه محلی WebView و در فضای برنامه ذخیره می‌شوند و برای استفاده عادی اینترنت لازم نیست.

## امکانات پیاده‌سازی‌شده
- داشبورد و شمارنده مشتریان، پرونده‌ها، نوبت‌های امروز و قطعات
- ثبت مشتری و اطلاعات تماس
- ثبت خودرو برای هر مشتری (مدل، سال، پلاک، شاسی و موتور)
- پرونده تعمیر شامل کیلومتر، شرح عیب، اقدامات و وضعیت؛ انتخاب تصویر
- نوبت‌دهی و باز کردن برنامه پیامک گوشی با متن یادآوری آماده
- ثبت قطعات و موجودی و قیمت خرید/فروش
- صدور فاکتور با محاسبه جمع، تخفیف و چاپ از مسیر چاپ اندروید/ذخیره PDF در صورت پشتیبانی دستگاه
- گزارش‌های خلاصه و خروجی CSV
- پشتیبان‌گیری JSON و بازیابی

## ساخت APK با Android Studio
1. Android Studio را نصب و پروژه را از پوشه `BarghKhodro` باز کنید.
2. اجازه دهید Gradle و Android SDK موردنیاز نصب/همگام‌سازی شوند.
3. از منوی Build گزینه **Build APK(s)** را بزنید.
4. فایل خروجی معمولاً در `app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود.

## نکات مهم نسخه اولیه
- همه اطلاعات محلی هستند؛ پاک‌کردن داده برنامه یا حذف برنامه می‌تواند اطلاعات را از بین ببرد. مرتب فایل پشتیبان بگیرید.
- تاریخ‌ها با قالب شمسی وارد می‌شوند و تاریخ پیش‌فرض نوبت و فاکتور بر اساس تقویم شمسی گوشی تنظیم می‌شود؛ انتخاب‌گر تقویم گرافیکی هنوز اضافه نشده است.
- پیامک با برنامه پیامک گوشی باز می‌شود و ارسال نهایی به تأیید کاربر و هزینه اپراتور وابسته است.
- Caller ID واقعی به مجوزهای حساس و در بسیاری از نسخه‌های اندروید به نقش برنامه تماس‌گیرنده پیش‌فرض نیاز دارد؛ در این نسخه پیاده‌سازی نشده است.
- این نسخه پایه قابل توسعه است و پیش از استفاده تجاری باید روی چند گوشی واقعی آزمایش، اعتبارسنجی فرم‌ها، امنیت و بازیابی داده تکمیل شود.


## وضعیت ساخت و محدودیت‌ها
- این بسته، سورس کامل پروژه اندروید است؛ APK کامپایل‌شده داخل آن نیست.
- برای تولید APK باید پروژه در Android Studio با Android SDK و Gradle همگام‌سازی و Build شود.
- ارسال پیامک با بازکردن برنامه پیامک گوشی انجام می‌شود و ارسال نهایی را کاربر تأیید می‌کند.
- Caller ID خودکار در این نسخه وجود ندارد؛ این قابلیت به پیاده‌سازی بومی اندروید، مجوزها و محدودیت‌های نسخه اندروید وابسته است.
- پیش از ثبت اطلاعات واقعی مشتریان، روی گوشی آزمایشی تست و پشتیبان‌گیری منظم انجام شود.

## ساخت فایل نصب APK

برای ساخت APK از GitHub Actions استفاده کنید؛ راهنمای کامل در فایل `BUILD_APK_FA.md` است. این محیط فعلی Android SDK/Gradle نصب‌شده ندارد و بنابراین فایل APK در همین محیط کامپایل نشده است.
